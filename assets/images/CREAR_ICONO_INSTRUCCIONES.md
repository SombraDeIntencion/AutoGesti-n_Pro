# Script para generar el ícono de la app
# Este ícono usa los colores de AutoGestión Max

# Instrucciones:
# 1. Opción A - Usar un generador online:
#    - Ir a https://icon.kitchen/ o https://www.appicon.co/
#    - Usar los colores:
#      * Fondo: Degradado de #17A2B8 a #0088CC
#      * Ícono: Auto blanco
#      * Acento: #FF9500 (naranja)
#    - Descargar como PNG 1024x1024
#    - Guardar en: assets/images/app_icon.png

# 2. Opción B - Convertir el SVG:
#    - Instalar Inkscape o usar https://convertio.co/svg-png/
#    - Convertir app_icon.svg a PNG 1024x1024px
#    - Guardar como app_icon.png

# 3. Opción C - Diseño personalizado en Canva/Figma:
#    Dimensiones: 1024x1024px
#    Colores:
#      - Fondo: #0088CC (azul)
#      - Gradiente secundario: #17A2B8 (turquesa)
#      - Ícono de auto: Blanco
#      - Detalle: #FF9500 (naranja)
#    Exportar como PNG

# Después de crear el ícono:
# flutter pub run flutter_launcher_icons

# Los colores de la marca:
PRIMARY_BLUE="#0088CC"
SECONDARY_CYAN="#17A2B8"
ACCENT_ORANGE="#FF9500"
WHITE="#FFFFFF"
